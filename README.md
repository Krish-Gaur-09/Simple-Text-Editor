# Simple Text Editor 📝

A simple GUI-based text editor built using Python and Tkinter.
It allows users to create, open, edit, and save text files
through a user-friendly graphical interface.

## Features

- Create a new text document
- Open existing `.txt` files
- Edit text in the editor
- Save text files to your computer
- Simple and clean graphical interface
- File menu with New, Open, Save, and Exit options

## Technologies Used

- Python
- Tkinter
- File Handling

## Requirements

- Python 3 installed on your computer
- Tkinter (usually included with standard Python installations)

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

   python text_editor.py

## Project Purpose

This project was created to practice Python GUI development
using Tkinter and to understand basic file handling operations.
